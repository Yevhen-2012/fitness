# Your Fitness Assistant — оболонка

Макет: https://www.figma.com/design/BSqQznbbM7SDFWjJ8Dr9Yj?node-id=5-414

Оболонка підключається з assets/assistant.js та assets/assistant.css. Код використовує звичайні HTML, CSS і JavaScript без нових залежностей. CSS обмежено контейнером #fitness-assistant; головна сторінка зберігає власну шкалу типографіки. Наявний workflow GitHub Pages уже публікує assets/ цілком, тому змінювати його не потрібно.

## Перевірка реалізації

- npm run check: синтаксис JavaScript, 27 локальних ресурсів, якірні посилання та демонстраційна форма — без помилок.
- У браузері перевірено 320, 390, 575/576, 767/768, 991/992, 1199/1200, 1699/1700 px та 844×390. Межі чату, поля вводу й навігації вміщуються; текст полів залишається 16 px.
- Перевірено відкриття й закриття, повернення фокуса через Escape, мобільний Shift+Tab, перемикання розділів, FAQ та неактивні кнопки надсилання.
- Реальну клавіатуру смартфона не перевірено; висота враховує VisualViewport API й safe area.

## Поточна поведінка

- Кнопка праворуч унизу відкриває чат. Початковий стан — закритий.
- Вікно на десктопі має ширину 408 px. На телефоні й низькому альбомному екрані воно займає доступний екран; прокручується лише його вміст.
- Get started, Quick answers і Talk to Anna відкривають відповідні розділи оболонки. FAQ містить статичні відповіді з контексту сайту.
- Find my training показує повідомлення про майбутній запуск і посилання на формати тренувань. Підбору програми чи алгоритму рекомендацій поки немає.
- Поля доступні для введення чернеток. Send message та Send enquiry неактивні. Подання форм додатково перехоплюється, method="dialog" не дає звичайного мережевого submit.
- Немає запитів до сервера, згенерованих відповідей, бронювання, localStorage, sessionStorage чи збереження персональних даних.
- Escape закриває чат; фокус повертається на кнопку відкриття. На мобільному екрані тло має inert, прокручування сторінки заблоковане, Tab залишається всередині чату.
- Медіагалерея сайту використовує власне модальне вікно; Escape спочатку обробляє його.

## Типографіка до реалізації

Збережено погоджений план: Cervino 800 для заголовків; Arial 400/700 для тексту й керування. Barlow Condensed / Arimo у Figma були замінами недоступних оригінальних шрифтів.

- До 576 px: заголовок привітання 32 px, назва помічника 18 px.
- 576–767 px: 32 / 18 px.
- 768–991 px: 36 / 18 px.
- 992–1199 px: 36 / 18 px.
- 1200–1699 px: 40 / 20 px.
- Від 1700 px: 40 / 20 px.
- Основний текст і поля: 16 px. Навігація й кнопки: 14 px. Підписи: 12 px в усіх діапазонах.
- Інтервали: заголовок 1,1; назва 1,25; текст і підписи 1,5; кнопки 1,4.
- На екранах до 992 px завширшки та до 500 px заввишки заголовок зменшується до 28 px. Основний текст і поля зберігають 16 px.
- Розміри задано CSS-змінними --fa-*. Мінімальна область натискання основних елементів — 44 px.

## Подальше підключення бота

Мережевий транспорт, відповіді, історію повідомлень і надсилання звернень потрібно реалізувати окремо. Поточні обробники керують лише видимістю, розділами та фокусом. Не вмикайте кнопки надсилання без реалізованого каналу й обробки його станів.
