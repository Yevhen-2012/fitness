# Fitness — стандартний експорт Webflow

Ця версія підготовлена без переписування дизайну й анімацій, на основі
`fitness-5cdfee.webflow.zip`.

## Що збережено

- Оригінальні `normalize.css`, `webflow.css`, `fitness-5cdfee.webflow.css`.
- Експортований `js/webflow.js`, усі Webflow Interactions та штатний lightbox.
- Точна версія jQuery 3.5.1 із вихідного HTML, з чинною перевіркою SRI.
- WebFont Loader 1.6.26, локальні шрифти, фотографії, відео та responsive-варіанти
  з ZIP. Montserrat і Oswald підключаються через Google Fonts, як в оригіналі.
- Вихідний вигляд, тексти, структура та поведінка відео й карти.

GSAP і Vite в цій версії не використовуються. Оптимізація не виконувалася:
зображення, відео, шрифти, CSS та `webflow.js` залишені байт у байт із ZIP.
Файл `migration-manifest.json` містить перелік 126 незмінених файлів і двох
адаптованих HTML-файлів.

## Адаптація для іншого хостингу

- jQuery, WebFont Loader і власний скрипт сайту збережено локально в `js/`.
- Власний `js/custom.js` збережено з вихідного GitHub commit; переходи на
  `fitness-5cdfee.webflow.io` замінено відносними адресами.
- Посилання меню й футера ведуть на локальні `index.html` та `about.html`.
- Дев'ять повних фотографій lightbox зіставлено з файлами ZIP за назвою й
  точним розміром. Різні `gallery-1.webp` не змішуються з `gallery-1_1.webp`.
- Іконки Play/Pause збережено локально.
- Форма залишається демонстраційною: Webflow-хостинг більше не обробляє її,
  тож локальний submit показує повідомлення без надсилання чи збереження даних.

## Запуск

Потрібен Node.js. Встановлювати npm-пакети або виконувати збірку не потрібно.
Відкрийте термінал у цій папці та запустіть:

```sh
npm run dev
```

Після запуску відкрийте `http://127.0.0.1:4174/fitness/`.
About: `http://127.0.0.1:4174/fitness/about.html`.
Перевірка файлів: `npm run check`.

Попередня версія з GSAP залишається в сусідній папці `site/` і може працювати
паралельно за адресою `http://127.0.0.1:4173/fitness/`.

Для перегляду потрібен HTTP-сервер; не відкривайте HTML через `file://`.
Залишайте термінал сервера працювати, поки переглядаєте сайт.

## GitHub Pages

1. Додайте вміст **цієї папки** до кореня репозиторію з гілкою `main`, включно
   з прихованими `.github/` та `.nojekyll`.
2. У **Settings → Pages → Source** виберіть **GitHub Actions**.
3. Виконайте push у `main` або запустіть workflow **Publish standard Webflow
   export**.

Workflow копіює HTML і каталоги `css`, `js`, `fonts`, `images`, `videos` в
артефакт Pages. Сервер, файли перевірок і документація не публікуються.
Маршрут About у стандартній версії — `about.html`.

Google Fonts і Google Maps залишаються зовнішніми сервісами, як у вихідному
експорті.
