# Your Fitness — один лендінг

Сайт: https://yevhen-2012.github.io/fitness/
Репозиторій: https://github.com/Yevhen-2012/fitness

Односторінковий макет: перший екран → формати тренувань → тренер → перші кроки → фото й відео → FAQ → контакт.

## Локальний запуск

Потрібен Node.js. Встановлення залежностей і збірка не потрібні.

```sh
npm run dev
```

Адреса: http://127.0.0.1:4174/fitness/ (також доступна коренева адреса сервера).

```sh
npm run check
```

## Поведінка

- Вибір тренування переноситься у форму.
- Галерея підтримує стрілки, Escape і повернення фокуса.
- Відео завантажується після натискання.
- Форма демонстраційна: не надсилає і не зберігає дані.
- Тексти послуг є прикладом для портфоліо, умови не є реальною пропозицією запису.
- `about.html` перенаправляє на `./#about`; `404.html` містить посилання на головну.
- Шрифти та медіа локальні, скопійовані з початкового експорту без перетворень. Оптимізація та Lighthouse не виконувались.

## Адаптив

- До 576 px: вертикальний перший екран, фото після кнопки, одна колонка.
- 576–767 px: текст і фото першого екрана поруч, картки в одну колонку.
- 768–991 px: планшетне компонування, компактне меню, три картки тренувань.
- 992–1199 px: повне меню та компактний десктопний макет.
- 1200–1699 px: основний десктопний макет.
- Від 1700 px: центрований контент для великих екранів.

Діапазони визначає ширина вікна у CSS-пікселях. Меню прокручується на низьких екранах; поля форми мають шрифт 16 px для запобігання автоматичному масштабуванню на iPhone. Декоративна смуга показує стільки гасел, скільки вміщується без обрізання.
